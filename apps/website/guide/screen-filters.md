# 设置屏幕滤镜

屏幕滤镜是托盘面板的第四个页面。页面标题写着「ICC 屏幕滤镜」，右侧标明「所有显示器」。

它通过 Windows Magnification API 的 `MagSetFullscreenColorEffect`，给整个桌面套上一张 5×5 颜色矩阵。这不是安装 ICC 描述文件，也不写入显示器的硬件亮度、对比度或色温。不需要管理员权限，也不必先打开 DDC/CI。

## 打开滤镜页面

<ol class="st-steps">
  <li>
    <span>01</span>
    <strong>打开托盘面板</strong>
    <p>ScreenTools 没有主窗口。点击系统托盘里的显示器图标。安装后还会注册默认全局快捷键 <code>Ctrl+Alt+D</code>，它只负责打开面板，不能直接切换滤镜。快捷键若被其他程序占用，注册会失败，这时仍从托盘图标进入。</p>
  </li>
  <li>
    <span>02</span>
    <strong>切到「屏幕滤镜」</strong>
    <p>面板有四个页面：屏幕信息、画面配置、刷新率与清晰度、屏幕滤镜。滤镜页顶部可以在「预设滤镜」和「自定义滤镜」之间切换。</p>
  </li>
  <li>
    <span>03</span>
    <strong>先预览</strong>
    <p>鼠标悬停或用键盘聚焦某个方案时，只更新下方的「实时预览」，桌面颜色还不会变。预览左侧是原色，右侧是当前方案。拖动分界线比较；分界线获得焦点后，左右方向键也能移动。</p>
  </li>
  <li>
    <span>04</span>
    <strong>点击后立即生效</strong>
    <p>点击方案会马上作用到所有显示器，不进入分辨率或 HDR 那种 20 秒确认。当前方案标为「使用中」。正在预览、但还没点下去的方案标为「预览」。再点一次已经生效的方案不会重复应用。</p>
  </li>
</ol>

卡片底部的说明是：「作用于所有显示器，退出 ScreenTools 后恢复」。Windows 这一接口不能只处理其中一台显示器，同一时间也只能有一个滤镜。

## 预设滤镜

预设分两组。「日常」里的阅读、夜间、灰度是固定颜色矩阵；「FPS 游戏」四项由和自定义滤镜相同的参数生成，界面上的说明如下。

<FilterSwatches />

| 方案     | 效果                                                           |
| -------- | -------------------------------------------------------------- |
| 原色     | 恢复 ScreenTools 启用滤镜之前读到的颜色矩阵                    |
| 阅读     | 红色保持 100%，绿色降到 92%，蓝色降到 75%                      |
| 夜间     | 红色 82%，绿色 68%，蓝色 45%，整体变暗并明显减少蓝色           |
| 灰度     | 使用代码中的 Windows 灰度矩阵，把画面转为灰阶                  |
| FPS 竞技 | 对比度 +8%，黑位 +5%，饱和度 112%。适度增强对比与色彩          |
| FPS 鲜艳 | 对比度 +6%，黑位 +3%，饱和度 135%。明显提高色彩饱和度          |
| FPS 暗场 | 对比度 −8%，黑位 +5%，饱和度 108%。提亮暗部，整体对比更柔和    |
| FPS 专注 | 对比度 +6%，黑位 +4%，饱和度 90%。适度降低饱和度，减少色彩干扰 |

点「原色」时，恢复的是启用滤镜前读到的那张矩阵，而不是随意写成一套新的颜色。滤镜只有在当时读到的矩阵是初始状态时才能打开。

全屏滤镜已经打开时，预览图本身也会带上这层颜色。要准确比较，先点回「原色」。

## 自定义滤镜

切到「自定义滤镜」。滑块只更新预览，不会立刻改桌面。说明文字是：「拖动滑块可立即预览；保存方案后可应用到所有显示器。」

| 参数               | 范围            | 步进 | 默认  |
| ------------------ | --------------- | ---- | ----- |
| 亮度               | −50% 到 50%     | 1%   | 0%    |
| 对比度             | −50% 到 50%     | 1%   | 0%    |
| 色温               | 3000K 到 10000K | 100K | 6500K |
| 黑位               | −20% 到 20%     | 1%   | 0%    |
| 红色 / 绿色 / 蓝色 | 20% 到 200%     | 1%   | 100%  |
| 饱和度             | 0% 到 200%      | 1%   | 100%  |

1. 拖动滑块，在预览里确认效果。不满意可以点「重置参数」，回到上表的默认值。
2. 输入方案名称。名称去掉首尾空格后须为 1 到 40 个字符。
3. 点「保存方案」。最多保存 20 个。存满后保存按钮不可用，再次保存会提示「自定义滤镜方案数量已达上限」。
4. 到上方「我的滤镜」里点击该方案，才会应用到所有显示器。悬停或聚焦同样只预览。

正在使用的自定义方案不能直接删除。删除按钮会禁用，提示「先切回原色再删除」。若仍尝试删除，会提示「请先关闭当前滤镜，再删除方案」。先点预设里的「原色」，再删除。

## 保存、退出与再次启动

当前选择会写入本机的 `control.json`。正常退出，或原生工作进程断开时，会把桌面颜色恢复成启用滤镜前读到的矩阵。

下次启动时，如果滤镜能力可用，而且上次不是「原色」，应用会重新套用上次的预设或自定义方案。选过「原色」也会被记住，避免下次启动又自动打开旧滤镜。上次的自定义方案若已不存在，则不会强行套用，并在运行记录里记下「上次使用的屏幕滤镜恢复失败」。

## 什么时候不能用

滤镜不可用时，预设按钮会禁用，卡片上直接显示原因，而不是静默失败。

- 刚打开面板时，可能短暂显示「正在检测屏幕滤镜能力」或「正在检测系统能力…」。
- 启用前如果已经有非初始的颜色矩阵，会禁用并提示「系统或其他程序正在使用颜色滤镜」。这样不会覆盖系统或其他程序已经生效的颜色效果。
- 滤镜生效后，如果矩阵被其他程序换掉，会提示「屏幕滤镜已被系统或其他程序替换」。
- 当前 Windows 环境无法加载滤镜组件、接口初始化失败，或原生工作进程已退出时，滤镜不可用。初始化或读写失败时，提示里会带上 Windows 错误码。
- 正在确认显示拓扑、分辨率或 HDR 等系统配置时，滤镜控件和其他页面一样暂时锁定。等 20 秒确认结束，或立即恢复之后，再回来调整。

应用失败时，选中状态保持上一次成功的方案，错误出现在面板底部，不会假装已经切换成功。

## 和画面场景不是一回事

「画面配置」里的日间、阅读、观影、夜间，会按显示器能力写入硬件亮度和对比度。日间是亮度 80、对比度 70，阅读是 45 和 65，观影是 60 和 80，夜间是 25 和 55。

「屏幕滤镜」里的阅读、夜间是另一套颜色矩阵。两边名称相近，但是两个开关，互不替代。硬件调节是否可用，仍取决于显示器和驱动是否支持对应的 DDC/CI 命令。
