# 设置屏幕滤镜

屏幕滤镜改变的是整个 Windows 桌面的颜色。页面小标题写作“ICC 屏幕滤镜”，但这里并不会把 ICC 配置文件写入显示器，也不修改亮度、对比度等硬件参数。

ScreenTools 调用系统自带的 Magnification API，用一个 5×5 颜色矩阵做全屏颜色效果。不需要管理员权限，也没有额外的授权步骤。同一时间只能启用一个滤镜，而且一定会作用到**所有显示器**，不能只改其中一台。

效果只在 ScreenTools 运行时保留。正常退出后，桌面会回到启用滤镜之前的颜色。选择本身会记在本机；下次启动时，如果滤镜仍然可用，会自动重新应用。

## 打开滤镜页

1. 安装并启动 ScreenTools。它只提供 **Windows x64** 版本，启动后没有主窗口。
2. 点击系统托盘里的显示器图标。默认也可以按 **Ctrl + Alt + D** 打开托盘面板。这个快捷键只负责打开面板，不能直接切换滤镜。应用设置里目前没有修改快捷键的选项；如果组合键已被占用，快捷键会注册失败，托盘图标仍然可用。
3. 面板底部有四个图标标签，从左到右是屏幕信息、画面配置、刷新率与清晰度、屏幕滤镜。标签只有图标，把鼠标停在第四个图标上会看到“屏幕滤镜”。
4. 进入后，页眉左侧是 **ICC 屏幕滤镜**，右侧标明 **所有显示器**。

## 选择预设

页面上方先在 **预设滤镜** 和 **自定义滤镜** 之间切换。预设分成两组，点下去就会立刻生效，不会进入画面配置那种 20 秒确认。

### 日常

| 名称 | 效果                                                                 |
| ---- | -------------------------------------------------------------------- |
| 原色 | 写回这次启用滤镜前读到的系统颜色。滤镜可用时，它就是当时的桌面原色。 |
| 阅读 | 红色不变，绿色降到 92%，蓝色降到 75%，画面更暖。                     |
| 夜间 | 降低整体亮度并进一步减少蓝色：红色 82%、绿色 68%、蓝色 45%。         |
| 灰度 | 使用 Windows 全屏颜色效果文档中的灰度矩阵，把画面转为灰阶。          |

### FPS 游戏

按钮上写的是“竞技 / 鲜艳 / 暗场 / 专注”，对应的预设名称是“FPS 竞技 / FPS 鲜艳 / FPS 暗场 / FPS 专注”。这些预设用固定参数生成，不能在预设上再调强度。

| 按钮 | 预设名称 | 说明                         | 参数                              |
| ---- | -------- | ---------------------------- | --------------------------------- |
| 竞技 | FPS 竞技 | 适度增强对比与色彩           | 对比度 +8%，黑位 +5%，饱和度 112% |
| 鲜艳 | FPS 鲜艳 | 明显提高色彩饱和度           | 对比度 +6%，黑位 +3%，饱和度 135% |
| 暗场 | FPS 暗场 | 提亮暗部，整体对比更柔和     | 对比度 −8%，黑位 +5%，饱和度 108% |
| 专注 | FPS 专注 | 适度降低饱和度，减少色彩干扰 | 对比度 +6%，黑位 +4%，饱和度 90%  |

### 怎么预览和应用

- 鼠标悬停，或用键盘聚焦某个预设时，下方的 **实时预览** 会先换成这个效果，按钮角标显示 **预览**。这时桌面颜色还没变。
- 点击后立即作用到所有显示器。正在使用的预设显示 **使用中**。再点一次当前预设不会重复应用。
- 预览图左边是原色，右边是当前效果。可以拖动中间的分界线，也可以在分界线控件上用方向键调整。
- 全屏滤镜已经打开时，这张预览图本身也会被系统效果染色。要看准确对比，先点回 **原色**。
- 卡片底部在可用时会写：“作用于所有显示器，退出 ScreenTools 后恢复”。

## 自定义滤镜

切到 **自定义滤镜** 后，上面是 **我的滤镜**，下面是参数。拖动滑块只会更新面板里的预览，不会立刻改变桌面。要真正用上这组参数，需要先保存成方案，再点击该方案。

| 参数               | 范围                       | 默认  |
| ------------------ | -------------------------- | ----- |
| 亮度               | −50% 到 50%                | 0%    |
| 对比度             | −50% 到 50%                | 0%    |
| 色温               | 3000K 到 10000K，每步 100K | 6500K |
| 黑位               | −20% 到 20%                | 0%    |
| 红色 / 绿色 / 蓝色 | 各 20% 到 200%             | 100%  |
| 饱和度             | 0% 到 200%                 | 100%  |

默认值对应没有改变的颜色。**重置参数** 会回到这组默认值，并刷新预览。

保存和使用：

1. 调好滑块，在“方案名称”里输入 1 到 40 个字符。
2. 点击 **保存方案**。方案出现在“我的滤镜”里，此时还没有应用到桌面。
3. 悬停方案可以预览；点击方案后，颜色才会作用到所有显示器，角标变为 **使用中**。
4. 最多保存 20 个方案。已满时不能再保存。

正在使用的方案不能直接删除，按钮会提示“先切回原色再删除”。请先改用其他滤镜或点 **原色**，再删除。如果仍然删除，面板底部会提示“请先关闭当前滤镜，再删除方案”。

系统暂时不允许使用滤镜时，预设和已保存方案都无法应用；参数仍可以调整并保存，等滤镜可用后再点击方案。

## 什么时候不能用

滤镜不可用时，按钮会禁用，原因直接写在卡片底部。应用失败时，面板最下方也会出现错误，并且仍保持上一次成功的选择。

- 启动时发现桌面颜色已经不是原色，例如 Windows 放大镜、系统颜色滤镜或其他程序正在使用同一接口。提示为“系统或其他程序正在使用颜色滤镜”。ScreenTools 不会覆盖它。
- 滤镜生效之后被系统或其他程序换掉。提示为“屏幕滤镜已被系统或其他程序替换”。
- 当前环境无法加载滤镜组件，或读取、写入颜色矩阵失败。失败时会带上 Windows 错误码。
- 面板正在等待一次显示配置的 20 秒确认，或正在处理其他操作。这时滤镜控件会暂时锁住，确认或恢复之后可以再试。

## 和画面场景的差别

“画面配置”里的日间、阅读、观影、夜间，是按**当前这一台**显示器的能力去写硬件亮度和对比度，需要显示器打开 DDC/CI。

“屏幕滤镜”里的阅读、夜间是另一套功能：它们不改显示器菜单里的亮度，而是给整个桌面加颜色矩阵，所有屏幕一起变，退出应用后恢复。两处名称可以相同，但不会互相代替。

## 会记住什么

当前选择保存在本机 Electron 用户数据目录的 `control.json` 里，不上传。其中记录预设，或自定义方案的编号。

- 正常退出时，桌面颜色会恢复成启用滤镜之前的状态。
- 下次启动且滤镜可用时，自动重新应用上次的预设。如果上次是自定义方案并且方案还在，也会自动应用。
- 选回“原色”同样会被记住，避免下次启动又套上旧滤镜。
- 如果保存的自定义方案已经不存在，启动时不会套用滤镜。

## 平台限制

滤镜不修改分辨率、刷新率、HDR 开关或输入源。它依赖 Windows 的全屏颜色效果，只随 Windows x64 版的 ScreenTools 提供。

独占全屏的游戏、受保护的视频、远程桌面，以及其他不经过桌面合成的画面，可能看不到这个颜色变化。滤镜也不能只作用于一个窗口或一台显示器。

::: tip 先确认能用
如果卡片底部出现“系统或其他程序正在使用颜色滤镜”，先关闭 Windows 放大镜或其他颜色滤镜，再重新打开 ScreenTools。不要期望两边的效果叠在一起。
:::
