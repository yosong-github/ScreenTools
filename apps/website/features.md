# 四个页面，管好你的显示器

ScreenTools 启动后常驻托盘。点击图标展开面板，底部四个图标在页面之间切换，没有独立主窗口。标题栏的齿轮进入应用设置，那不是第五个标签。下面的截图来自当前桌面应用。

## 屏幕信息

页首是显示器预览，写出当前分辨率、刷新率，以及主显示器或活动显示器。旁边一行标出当前画面和连接方式。

输入源默认只展示当前接口。打开「允许切换」之后才能点选其他接口，应用还会再问一次「确定切换显示器输入源？」。列表来自这台显示器上报的能力，常见名称包括 HDMI 和 DP。关闭面板或窗口失焦后，这个开关会回到关闭。

亮度是显示器硬件亮度，走 DDC/CI。显示器音量只在设备提供可控音量时可以拖动，否则会写明当前设备未提供。

## 画面配置

底部标签的名称是「画面配置」。打开之后，页内标题是「画面与配置」，并标明「当前显示器」。

显示拓扑有扩展、复制、仅主屏、仅外屏。提交后需要在 **20 秒内确认**，否则会尝试恢复。

场景有日间、阅读、观影、夜间。它们写入硬件亮度和对比度：日间是 80 和 70，阅读是 45 和 65，观影是 60 和 80，夜间是 25 和 55。设备和驱动不支持对应命令时，场景不会硬改。

硬件亮度在松开滑块时提交，设备响应可能要几秒。对比度是显示器硬件对比度。HDR / 高级颜色只在当前显示器报告支持时出现，开关和拓扑一样进入确认。

<img class="feature-shot" src="/images/picture-settings.png" alt="画面配置页：显示拓扑、场景、硬件亮度、对比度和 HDR" />

## 刷新率与清晰度

底部标签的名称是「刷新率与清晰度」。页内标题是「分辨率与刷新率」，并写出当前有多少种模式。

刷新率是一组选项，分辨率是列表。列表只包含这台显示器上报的模式，不会展示设备没提供的分辨率。系统缩放比例仍由 Windows 设置管理。更改后同样留意 20 秒确认。

<img class="feature-shot" src="/images/display-modes.png" alt="刷新率与清晰度页：刷新率选项和分辨率列表" />

## 屏幕滤镜

第四个标签的名称是「屏幕滤镜」。页内标题是「ICC 屏幕滤镜」，并写明效果作用于「所有显示器」。它用 Windows 全屏颜色矩阵改变整个桌面的颜色，不安装 ICC 描述文件，也不改写显示器硬件参数。

预设分「日常」和「FPS 游戏」。日常是原色、阅读、夜间、灰度。FPS 游戏是竞技、鲜艳、暗场、专注。悬停或键盘聚焦只更新「实时预览」：左侧是原色，右侧是当前方案，分界线可以拖动。点击方案后立即生效，不进入 20 秒确认。卡片上的说明是：「作用于所有显示器，退出 ScreenTools 后恢复」。

<img class="feature-shot" src="/images/filter-presets.png" alt="屏幕滤镜预设：日常与 FPS 分组，以及左右对比的实时预览" />

## 自定义滤镜

仍在屏幕滤镜页，切到「自定义滤镜」。上方是「我的滤镜」：悬停已保存的方案只更新预览，点击才会应用到所有显示器。

滑块包括亮度、对比度、色温、黑位、红、绿、蓝和饱和度。色温默认 6500K。拖动滑块只更新预览，说明文字是：「拖动滑块可立即预览；保存方案后可应用到所有显示器。」点「重置参数」回到默认值。名称去掉首尾空格后为 1 到 40 个字符，最多保存 20 个方案。正在使用的方案要先回到原色才能删除。

<img class="feature-shot" src="/images/filter-custom.png" alt="自定义滤镜：我的滤镜、实时预览、色温和其他滑块" />

和「画面配置」里的日间、阅读、观影、夜间不是同一件事：那些场景写入硬件亮度与对比度；滤镜页的阅读、夜间是颜色矩阵。

## 应用设置

点标题栏的齿轮进入。这时底部不再是四个图标，而是返回按钮和「应用设置」。

主题有跟随系统、白色、黑色，只影响 ScreenTools 面板，不会更改 Windows 主题。开机自启动让安装版在登录 Windows 后于托盘后台启动，不弹出主窗口；也可以在 Windows 的「启动应用」里关闭。未安装的运行方式没有这项。版本更新显示当前版本，检查本仓库的 GitHub Release。下载完成后要点「确认安装」，应用才会退出并打开安装程序。

<img class="feature-shot" src="/images/app-settings.png" alt="应用设置：跟随系统、白色、黑色主题，开机自启动和版本更新" />

## 本地优先

显示配置通过 Windows 本机接口处理，显示器硬件参数通过 DDC/CI 读取与写入，不依赖云服务。不同显示器对亮度、音量、输入源等命令的支持情况可能不同。
