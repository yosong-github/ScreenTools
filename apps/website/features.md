# 三个页面，管好你的显示器

ScreenTools 启动后常驻托盘。点击图标展开面板，在三个页面之间切换；无需打开独立主窗口。下面的截图来自当前桌面应用。

## 屏幕信息

查看当前显示器的分辨率、刷新率、主屏状态和连接方式。输入源默认仅展示；如需切换，须先主动打开“允许切换”。显示器支持相应 DDC/CI 能力时，还可以调整硬件亮度和内置音量。

<img class="feature-shot" src="/images/screen-info.png" alt="屏幕信息页面：设备预览、输入源、亮度和音量" />

## 画面配置

在扩展、复制、仅主屏和仅外屏之间切换。日间、阅读、观影、夜间场景可快速应用对应的屏幕参数；支持的设备还能调整亮度、对比度与 HDR / 高级颜色。

显示拓扑和 HDR 等系统配置提交后需要在 **20 秒内确认**，否则会尝试恢复原配置。

<img class="feature-shot" src="/images/picture-settings.png" alt="画面配置页面：显示拓扑、场景、亮度和对比度" />

## 刷新率与清晰度

按当前显示器上报的可用模式选择刷新率与分辨率。模式列表随设备能力变化，不会展示设备未提供的选项。系统缩放比例仍由 Windows 设置管理。

<img class="feature-shot" src="/images/display-modes.png" alt="刷新率与清晰度页面：刷新率选项与可滚动的分辨率列表" />

## 本地优先

显示配置通过 Windows 本机接口处理，显示器硬件参数通过 DDC/CI 读取与写入，不依赖云服务。不同显示器对亮度、音量、输入源等命令的支持情况可能不同。
